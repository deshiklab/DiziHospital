[Articles](https://smart-hospital.in/articles)[Reports](https://smart-hospital.in/category/reports)

---

To check Inventory Issue report, go to **Reports > Inventory Issue Report**. Here select the **Time Duration** then click on**Search** button. Here you can see **Inventory issue** details like **Item, Item Category, Issue - Return, Issue To, Issued By, Quantity** etc. Also you can download this report as PDF.
