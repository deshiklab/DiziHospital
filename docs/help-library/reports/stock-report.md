To check Stock Report report, go to **Reports > Stock Report**.  
  
![](../assets/stock-report/1.jpg)  
  
Here select **Medicine Category, Stock Type** then click on **Search** button.  
  
![](../assets/stock-report/2.jpg)  
  
  
Here you can see Expiry Medicine Report details like **Medicine Name, Medicine Company, Medicine Category, Medicine Composition,Medicine Category, Medicine Group, Unit** and **Available Qty (Quantity).**Also you can download this report as PDF.
