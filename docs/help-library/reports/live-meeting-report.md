### Live Meeting Report

Sat, 30 Oct, 2021

[Articles](https://smart-hospital.in/articles)[Reports](https://smart-hospital.in/category/reports)

---

To check Live Meeting report, go to **Reports >** **Live Meeting** **Report**. Here select the **Time Duration, Created By** then click on**Search**button. Here you can see Live Meeting details like **Meeting Title, Date, Api Used, Create By and Total Join**. Also you can download this report as PDF.
