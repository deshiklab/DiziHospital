### Live Consultation Report

Sat, 30 Oct, 2021

[Articles](https://smart-hospital.in/articles)[Reports](https://smart-hospital.in/category/reports)

---

To check Live Consultation report, go to **Reports >** **Live Consultation** **Report**. Here select the **Time Duration, Created By** and **OPD / IPD** then click on **Search** button**.** Here you can see Live Consultation details like **Consultation Title, Patient, Date, Api Used, Create By and Total Join**. Also you can download this report as PDF.
