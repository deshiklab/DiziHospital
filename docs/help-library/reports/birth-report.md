To check Birth report, go to **Reports > Birth Report**. Here select the **Time Duration** **and Gender** then click on**Search** button. Here you can see Birth details like **Reference Number, Case ID, Child Name, Gender, Birth Date, Weight, Mother Name, Father Name, Report** etc. Also you can download this report as PDF.
