To check Death report, go to **Reports > Death Report**. Here select the **Time Duration** **and Gender** then click on**Search** button. Here you can see Death details like **Reference Number, Case Id, Guardian Name, Patient Name, Gender, Death Date, Report** etc. Also you can download this report as PDF.
