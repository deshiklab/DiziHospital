### Can I use Smart Hospital on localhost or local LAN network?

Tue, 02 Nov, 2021

[Articles](https://smart-hospital.in/articles)[FAQ](https://smart-hospital.in/category/faq)

---

Yes, you can use Smart Hospital on localhost installation (using XAMPP or WAMP) and **access it in your local LAN** (Local Area Network) from other pc in network. How to configure Smart Hospital local LAN network please [check this article](https://smart-hospital.in/article/configure-smart-hospital-to-use-in-local-lan-network " Configure Smart School To Use In Local LAN Network").
