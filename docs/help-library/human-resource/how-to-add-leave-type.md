### How to add Leave Type?

Tue, 26 Oct, 2021

[Articles](https://smart-hospital.in/articles)[Human Resource](https://smart-hospital.in/category/human-resource)

---

To add leave for a staff first you will have to create Leave Type.  To add leave type, go to **Setup >** **Human Resource > Leave Type** then enter **Name** and then click on **Save** button.  
  
  
  
You can view this added record in the **Leave Type** **List** on the right side of the page.

To edit leave type click on **Edit** icon and to delete leave type click on **Delete** icon present in the Leave Type List.
