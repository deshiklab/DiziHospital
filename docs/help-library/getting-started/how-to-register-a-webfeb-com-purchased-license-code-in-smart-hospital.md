### How to register a Webfeb.com purchased License Code in Smart Hospital?

**Smart Hospital License Registration**  
  
After installing Smart Hospital, log in to the application. On your first login, you will see the following alert message at the top of the dashboard:  
  
Alert! You are using an unregistered version of Smart Hospital. Please click here to register your purchase code for Smart Hospital.  
  
Click "**Click Here**" to open the Register Your Purchase Code dialog.  
  
You will be prompted to enter the following details:  

* Smart Hospital License Key
* Signing Key

  
How to Obtain the License Key and Signing Key  
  
Log in to your Webfeb account.  
  
**Go to the Licenses page**: <https://webfeb.com/dashboard/licenses>   
  
Locate your Smart Hospital license and click Manage Registered Domains.  
  
Register the domain where Smart Hospital is installed.  
  
Once the domain is registered successfully, the Signing Key will be generated. Copy the Signing Key.  
  
Return to the Licenses page and click Download Certificate.  
  
Open the downloaded certificate to find your License Key.  
  
Copy both the License Key and Signing Key.  
  
Return to the Register Your Purchase Code dialog in Smart Hospital, paste both keys into their respective fields, and click Register Now.  
  
After successful registration, your Smart Hospital installation will be activated, and the registration alert will no longer appear.  
  
Note: Ensure that the registered domain matches the domain where Smart Hospital is installed. Otherwise, the activation process will fail.
