**Released Date 21 August, 2025  
  
General Changes**

* Patient's age is now automatically updated
* In the All Transactions Report, refunds are now displayed with a negative (-)sign.
* Updated Zoom SDK
* Removed Edit option from the Roster list
* Updated Duty Roster Shift page with Required validation
* OPD list page updated with Today's OPD, Upcoming OPD, and Old OPD tabs
* Appointment list page updated with Today's Appointment, Upcoming Appointment, and Old Appointment tabs

**Feature Enhancement**

* Added Multi Branch addon
* Added QR Code Attendance addon
* Added Two Factor Authentication addon
* Added addon install/uninstall module
* Added TPA support in the Pharmacy module
* Added medicine (item) wise discount in pharmacy bill
* Added option to collect payment processing fees (for payment gateways)
* Added "Created By" field in all modules
* Added Stock Report in Pharmacy.
* Added Pathology Balance Report.
* Added Radiology Balance Report.
* Added Balance Amount Report.
* Added Appointment in All Transactions Report
* Added Patient TPA ID column in TPA Report
* Added Source column in Staff Attendance page
* Added Barcode or QR Code in the patient panel
* Added TPA option in the OPD/IPD Balance Report
* Appointments (added from the front site or patient panel) now display in the admin panel.
* Added Blood Component on the Billing module.
* Added Date and Venue Front site on the Event page
* Added Delete option in the Leave Request module
* Added IPD in patient dashboard graph.
